# Code of Conduct

Cliostra is an open-source technical project. Participation should make the project safer, clearer, and easier to contribute to.

## Expected behavior

Contributors and maintainers should:

- communicate respectfully and in good faith;
- critique ideas and code without attacking people;
- document technical claims and provider behavior when possible;
- acknowledge uncertainty instead of presenting assumptions as facts;
- respect security boundaries and responsible-disclosure practices;
- avoid discriminatory, harassing, threatening, or abusive behavior;
- keep discussions relevant to the project and its users;
- welcome contributors with different levels of experience.

## Unacceptable behavior

The following are not acceptable in project spaces:

- harassment, insults, intimidation, or targeted hostility;
- discriminatory language or exclusion based on personal characteristics;
- publishing private information without permission;
- deliberate disruption of technical discussions;
- encouraging credential theft, account abuse, quota evasion, or unsafe bypasses under the guise of project contributions;
- knowingly submitting malicious code or misleading security information.

## Scope

This code applies to repository issues, pull requests, discussions, reviews, project chat spaces, and other places where someone is acting as a representative of Cliostra.

## Enforcement

Maintainers may edit, remove, reject, lock, or moderate contributions and discussions that violate these expectations. Repeated or severe violations may result in exclusion from project spaces.

When possible, enforcement decisions should be proportional, documented, and focused on protecting contributors and the project.
